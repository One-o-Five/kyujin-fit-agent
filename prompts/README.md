# prompts

LLM に渡すプロンプトを、コードから分離して管理する。

## 構成

```
prompts/
└── <用途>/
    ├── v1.md
    └── v2.md
```

- 1ファイルが1つのシステムプロンプト。コードからは `loadPrompt('<用途>', 'v1')` で読み込む。
- 用途の名前は小文字の英数字とハイフン、バージョンは `v` + 数字とする。

## 運用ルール

- 評価に使ったバージョンのファイルは書き換えない。変更する場合は新しいバージョンのファイルを作る。評価結果とプロンプトの対応が崩れないようにするため。
- 変更の理由と評価結果の変化は、PR に記録する。
