# kyujin-fit-agent

**日本の求人票に特化した**、求人票と職務経歴書のマッチング分析サービスです。LLMで両者を比較し、要件ごとのマッチ度、面接でのアピール方法・補強すべきスキル、応募前に確認すべき労働条件を提示します。

> 🚧 開発中（2026年11月〜）。バックエンド・フロントエンドの構築フェーズです。

## 解決したい課題

転職活動では、求人票ごとに「自分がどの要件を満たしていて、何が足りないか」を読み解く作業を繰り返します。このサービスでは、求人票を貼り付けるだけで次の結果が得られます。

- 必須要件・歓迎要件・年収・勤務条件の整理
- 要件ごとの ○（充足）△（一部充足）×（未充足）判定と、根拠となる職務経歴書の記述
- △・×の要件に対する、アピール方法または学習内容の提案
- これまでの分析で多く未充足と判定された要件 TOP5

### 日本の求人票に特化した点

英語圏の既存ツールはATS（応募者管理システム）のキーワード一致の最適化が中心です。本サービスは日本の転職活動に合わせ、次の点に対応します。

- 固定残業代の内訳、試用期間、業務・就業場所の変更の範囲などの構造化と、記載がない項目の表示
- 要件定義〜試験といったSIerの工程経験を踏まえた判定
- キーワードの一致ではなく、書類選考・面接で使える根拠とアピール方法の提示
- 外国籍エンジニア向けの情報（日本語要件、英語の使用、ビザ）の整理

## 主な機能（MVP）

- 招待コード制の会員登録・ログイン
- 職務経歴書の登録（テキスト / PDF / DOCX）
- 求人分析と結果の保存・一覧
- 日本の求人票に特化した条件の構造化
- 利用量制限によるコスト制御

詳細は [要件定義](docs/requirements.md) を参照してください。

## ローカルでの開発

Node.js 22 以上と pnpm が必要です。

```bash
pnpm install
pnpm dev:api   # API: http://localhost:8787/api/health
pnpm dev:web   # 画面: http://localhost:5173
```

API仕様（OpenAPI）は `http://localhost:8787/api/openapi.json` で確認できます。

### リクエスト例

求人テキストは空白を正規化したうえで、150〜10,000文字の範囲で受け付けます。範囲外の場合は共通のエラー形式で 400 を返します。

```bash
curl -i -X POST http://localhost:8787/api/analyses \
  -H 'content-type: application/json' \
  -d '{"rawText":"短い求人票"}'
```

```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "入力値が正しくありません",
    "details": [{ "path": "rawText", "message": "求人テキストは150文字以上で入力してください" }]
  }
}
```
